# C++ Templates: от простого к сложному

Учебный репозиторий: 10 коротких автономных уроков, которые последовательно
проводят от базовых шаблонов функций до CRTP, policy-based design и вычислений
на этапе компиляции.

Каждый урок — отдельный файл в `lessons/` с рабочим примером и `static_assert`,
которые проверяются уже во время компиляции.

## Требования

- Компилятор с поддержкой C++20 (проверено на `g++ 13`).
- `make` (необязательно — уроки собираются и вручную).

## Сборка и запуск

```bash
make          # собрать все уроки в build/
make run      # собрать и по очереди запустить все уроки
make clean    # удалить build/
```

Собрать и запустить один урок напрямую:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic lessons/01_function_templates.cpp -o build/01
./build/01
```

## Урок 1. Шаблоны функций

Шаблон функции — это чертёж. Компилятор выводит типы из аргументов вызова и
создаёт отдельную функцию под каждый набор типов.

- `max_value<T>(const T&, const T&)` — один параметр `T`, возвращает ссылку, помечен
  `constexpr` и проверяется через `static_assert`.
- `add<T, U>(T, U)` — два независимых параметра, тип результата выводится.
- `narrow_cast<To>(From)` — параметр шаблона указан явно.

Ключевая мысль: шаблон сам по себе не существует, пока его не инстанцируют.

## Урок 2. Шаблоны классов

Класс-шаблон параметризуется типом и создаёт отдельный тип под каждый аргумент.

- `Box<T>` — обёртка над значением с `get`/`set`, а также шаблонные методы
  `map<F>` (меняет тип параметра) и `operator==` (сравнение с `Box<U>`).
- `Stack<T>` — минимальный контейнер: тип элемента хранится в параметре.

Ключевая мысль: `Box<int>` и `Box<std::string>` — два разных, независимых типа.

## Урок 3. Полная специализация

Явная специализация задаёт отдельную реализацию для конкретного типа.

- `TypeName<T>` — общий случай возвращает «неизвестный тип», а специализации
  для `int`, `double`, `std::string` возвращают своё имя.
- `to_string<Status>` — специализация функции для перечисления `Status`.

Ключевая мысль: компилятор сначала ищет точную специализацию и лишь потом
берёт общий шаблон.

## Урок 4. Частичная специализация

Частичная специализация фиксирует не все аргументы, а их форму.

- `ScalarTraits<T*>` — специализация для любого указателя.
- `ScalarTraits<T[N]>` — специализация для любого массива; вложенные массивы
  считаются рекурсивно (`int[3][4]` → 2 измерения).

Ключевая мысль: частичных специализаций может быть много, и компилятор выбирает
наиболее подходящую.

## Урок 5. Нетиповые параметры

Параметром шаблона может быть значение, известное на этапе компиляции.

- `FixedArray<T, N>` — размер массива встроен в тип, динамической памяти нет.
- `square<N>()` — результат доступен в `static_assert`.
- `static constexpr size()` возвращает `N` как обычную константу.

Ключевая мысль: значение-параметр — часть типа, поэтому `FixedArray<int, 3>` и
`FixedArray<int, 5>` несовместимы.
